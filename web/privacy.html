What Zentho stores

Zentho is a personal finance tracker. On this device it stores household profiles, accounts, transactions, budgets, goals, holdings, settings, and optional quote-API tokens you paste in Settings. That data stays in local app storage unless you sign in.

Optional Google account

If you tap Sign in with Google, Zentho uses Google sign-in and stores a copy of the same ledger in Google Cloud Firestore under your user id so it can sync across devices. Sign-out does not wipe the copy on this device. Clearing all data in Settings wipes this device; cloud copies must be deleted from the Google account / Firebase project by the operator if required.

Network calls

  • Exchange rates (Frankfurter, with an HTTPS fallback).
  • Market quotes (Yahoo Finance; optional Finnhub, Alpha Vantage, Twelve Data keys you supply).
  • Google / Firebase when you choose to sign in (authentication and Firestore).
  • Bill scan may send an image to an OCR endpoint if that feature is used.

Traffic is HTTPS. The app does not enable cleartext HTTP.

What we do not do

Zentho does not sell personal or financial data. Android Auto Backup of app data is turned off. Optional API tokens stay on the device.
